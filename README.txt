HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a browser to preview the invitation.
3. Upload the contents of the mpilo_21st_invitation folder to your web hosting public folder to publish it.
4. To change event details, edit the visible details in index.html and the matching eventDetails object in script.js.
